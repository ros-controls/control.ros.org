Detailed Description

template<typename T, std::size_t Capacity>
class realtime_tools::LockFreePooledSPSCQueue< T, Capacity >

Wait-free SPSC queue for large or move-only types, backed by a preallocated pool.

The elements live in a fixed pool of Capacity slots. Only slot indices travel through two LockFreeSPSCQueues: one with the filled slots (producer -> consumer) and one with the free slots (consumer -> producer). Elements are therefore never copied by the queue, can be move-only and are written/read in place with produce()/consume().

Template Parameters
TElement type. Must be default constructible (all slots are constructed up front).
CapacityNumber of slots in the pool, must be > 0.
Note
Exactly one producer thread (push/produce) and exactly one consumer thread (pop/consume). empty() may only be called from the consumer thread.
The queue holds Capacity * sizeof(T) bytes inline, so allocate it on the heap or as a member if it is large.
