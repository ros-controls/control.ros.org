Detailed Description

Mock hardware for a rotary (Furuta) inverted pendulum.

Angle conventions (chosen to match the controller, NOT the URDF joint zero): q1 (motor_joint) : arm angle, 0 = wherever the operator centred the arm, mechanically limited to +-135 deg by the lid bosses. q2 (pendulum_joint) : 0 = UPRIGHT, +-pi = hanging. Always reported wrapped into [-pi, pi].

The URDF's arm_to_pendulum zero is the hanging pose; this interface offsets that by pi so the controller sees the usual "error = q2" upright convention.
