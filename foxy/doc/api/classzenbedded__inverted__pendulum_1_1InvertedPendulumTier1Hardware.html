Detailed Description

Topic-based hardware interface for Inverted Pendulum Tier 1.

Subscribes to sensor_msgs/msg/JointState from the Tier 1 Zephyr MCU firmware and publishes control_msgs/msg/JointCommand acceleration back to the MCU.
