Detailed Description

Statistics (average, minimum, maximum, standard deviation (population) and sample count) over the samples observed within the most recent window_duration seconds. Unlike MovingAverageStatistics, an old outlier leaves the statistics once the window has moved past it, so they describe the recent behaviour rather than the whole history.

The window is split into NUM_BUCKETS time buckets, each holding the running statistics of its samples, so the memory is constant and independent of the sample rate, and add_measurement() is O(1) and never allocates. The price is the resolution of the window's trailing edge: it advances one bucket at a time, so the statistics cover between (NUM_BUCKETS - 1) / NUM_BUCKETS of the duration and the full duration.

The time of a sample is given by the caller, so the window follows whichever clock drives the measurements (e.g. simulation time). If the time goes back past the current bucket (e.g. a reset simulation), the window is restarted.

The window ends at the latest sample, not at the current time: if the samples stop arriving (e.g. a stalled asynchronous component), get_statistics() keeps returning the last window until a new sample comes in, like the since-startup statistics do.

A non-positive (or non-finite) duration disables the collector: add_measurement() is a no-op. When statistics are not available, e.g. no observations have been made, NaNs are returned.
