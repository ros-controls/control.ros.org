Benchmarking

Benchmarks for the Zenbedded transport - Zenoh vs DDS (micro-ROS), Tier 1 vs Tier 2, and max control frequency across data sizes.

Default test setup: ESP32-S3, WiFi, Zenoh client mode, Best Effort QoS, ROS 2 Lyrical. All values TBD until measured.

Data sizes are expressed in float64 values, state to command at a 2:1 ratio. Tier 2 schemas carry exactly the fields they define.

Notes
