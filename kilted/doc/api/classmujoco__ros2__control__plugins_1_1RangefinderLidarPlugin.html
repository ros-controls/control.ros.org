Detailed Description

Plugin wrapper for MuJoCo rangefinder-based lidar sensors.

This handles the legacy pattern where individual mjSENS_RANGEFINDER sensors are grouped by name convention (e.g. lidar_name-0, lidar_name-1, ...) and published as LaserScan messages.
