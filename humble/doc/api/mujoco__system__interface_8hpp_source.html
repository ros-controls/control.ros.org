450 // rely on mj_data_control_->xfrc_applied to hold plugin forces across physics iterations.
451 // Instead, the control thread (read()) zeroes mj_data_control_->xfrc_applied before every
452 // plugin update, lets plugins write fresh forces, then copies the result here. The physics
453 // thread uses this buffer (not mj_data_control_->xfrc_applied) when composing each mj_step.
