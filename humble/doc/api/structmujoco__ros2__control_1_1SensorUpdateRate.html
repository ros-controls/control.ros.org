Detailed Description

Gates how often a sensor's state interfaces are refreshed, set per ros2_control sensor via the update_rate parameter (Hz). Between refreshes the last value (noise included) is held, so e.g. a 20 Hz IMU read by a 200 Hz controller manager changes once every 10 cycles.

Parameters
periodSeconds between refreshes; 0 (the default, update_rate unset) refreshes on every read().
next_update_timeSimulation time at or after which the next refresh is due.
